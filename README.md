## Ausgewählte Projekte

### [Operations Hub](https://github.com/Nico89x/nico-joschke-automation-portfolio/tree/main/projects/multi-agent-ai-operations-hub)

Ein lokaler n8n-Prototyp verarbeitet Automatisierungsanfragen vom validierten Eingang bis zum technischen Entwurf. Dublettenprüfung, Wissensbasis, Audit-Log und menschliche Freigabe machen Entscheidungen nachvollziehbar.

**Stack:** n8n · JavaScript · PostgreSQL/pgvector · Docker Compose  
[Workflow-Screenshots](https://github.com/Nico89x/nico-joschke-automation-portfolio/blob/main/projects/multi-agent-ai-operations-hub/docs/screenshots/README.md) · [Demo-Anleitung](https://github.com/Nico89x/nico-joschke-automation-portfolio/blob/main/projects/multi-agent-ai-operations-hub/docs/DEMO_RUNBOOK.md)

### [Grocery Store Automation](https://github.com/Nico89x/ai-grocery-store-automation)

Eine interaktive 3D-Demo zeigt Bestellungen, Lagerbuchungen, Warnungen und Wiederholungen nach einem Fehler. Die Verarbeitung läuft lokal; ein optionaler n8n-Webhook bestätigt abgeschlossene Demo-Bestellungen.

**Stack:** TypeScript · React · React Three Fiber · n8n · Playwright  
[Demo ausprobieren](https://nico89x.github.io/ai-grocery-store-automation/#/simulation) · [Architektur und Entscheidungen](https://github.com/Nico89x/ai-grocery-store-automation/blob/main/docs/CASE_STUDY.md)

### [ReleaseWatch](https://github.com/Nico89x/nico-joschke-automation-portfolio/tree/main/projects/release-support-triage)

Ein Node.js-Adapter ergänzt synthetische Support-Tickets um öffentliche GitHub-Release-Metadaten und bereitet einen Entwurf zur Prüfung vor. Tests behandeln unter anderem Timeouts, Rate-Limits und doppelte Anfragen; der zusätzliche n8n-Export ist noch nicht vollständig live geprüft.

**Stack:** JavaScript · Node.js · GitHub REST API · n8n-Workflow-Export

### [Lead-to-Offer](https://nico89x.github.io/nico-joschke-automation-portfolio/#lead-to-offer)

Drei gekoppelte Workflows zeigen den Weg vom Lead-Eingang über Validierung, Scoring und Dublettenprüfung bis zum CRM und internen Angebotsentwurf. Die Fallstudie enthält bereinigte n8n-Exporte und getrennte Fehlerpfade.

**Stack:** n8n · JavaScript · Webhooks · REST APIs · Notion CRM

## Wie ich arbeite

- **Saubere Daten:** Eingaben prüfen, Daten normalisieren und Dubletten bewusst behandeln.
- **Verständliche Fehlerfälle:** API-Ausfälle, ungültige Eingaben und Wiederholungen berücksichtigen.
- **Prüfbare Ergebnisse:** Architektur, Tests und bekannte Grenzen dokumentieren.

Meine technische Praxis stammt aus eigenen Portfolio- und Testprojekten. KI-Unterstützung und technische Grenzen sind in den Projekten offengelegt. Beim Operations Hub sind die zentrale Agentenlogik und Test-Embeddings deterministische Baselines; die Demo führt keine realen CRM-Schreibvorgänge oder Nachrichten aus.

**Standort:** Karlsruhe, Deutschland · **Ziel:** Junior n8n Developer / Workflow Automation / API-Integration
