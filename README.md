## Was ich in meinen Projekten umsetze

- **Workflow- und API-Integration:** n8n, REST APIs, Webhooks, JSON und JavaScript; Validierung, Routing und Dublettenvermeidung.
- **Daten und lokale Infrastruktur:** PostgreSQL, SQL, pgvector und Docker Compose.
- **Kontrollierte AI-Workflows:** Quellenprüfung, strukturierte Ausgaben, Human-in-the-Loop und nachvollziehbare Audit-Logs.
- **Qualität:** automatisierte Tests, Git und GitHub Actions; dokumentierte Fehlerfälle und Sicherheitsgrenzen.

## Hauptprojekt: Multi-Agent AI Operations Hub

Ein lokaler n8n-Prototyp macht aus unstrukturierten Automatisierungsanfragen einen prüfbaren Entwurf: Validierung → Dublettenprüfung → wissensgestützte Planung → Audit-Log → menschliche Entscheidung.

## Ehrliche Einordnung

Meine technische Erfahrung stammt aus eigenen Portfolio- und Testprojekten, nicht aus kommerzieller IT-Berufserfahrung. Die Demo nutzt synthetische Daten und führt keine realen CRM-Schreibvorgänge oder Nachrichten aus. Die zentrale Agentenlogik und Test-Embeddings sind deterministische Baselines; der lokale LLM-Schritt ist separat und hat kein Ausführungsrecht.
